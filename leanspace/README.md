# LeanSpace — Flutter App

Android-first Flutter app for LeanSpace. Run from this directory.

## Prerequisites

1. Flutter SDK (stable) — `flutter doctor`
2. Android SDK (command-line, no Android Studio required)
3. Physical Android phone with **USB debugging** enabled
4. Supabase project — copy keys into `env.json`

See `../execution/11-DEV-SETUP.md` and `../execution/00-IMPLEMENTATION-READINESS.md`.

## First-time setup

```powershell
# 1. Configure Supabase
copy env.json.example env.json
# Edit env.json with your SUPABASE_URL and SUPABASE_ANON_KEY

# 2. Install dependencies
flutter pub get

# 3. Connect phone via USB, verify device
adb devices

# 4. Run on device
flutter run --dart-define-from-file=env.json
```

## Languages

The app ships with full **internationalization (i18n)** support for 15 languages. The user can switch the in-app language from **Settings → Language** — the choice is persisted with `shared_preferences` and overrides the system locale.

Supported languages:

| Code | Language | Code | Language |
|---|---|---|---|
| `en` | English | `de` | Deutsch |
| `es` | Español | `fr` | Français |
| `it` | Italiano | `pt` | Português |
| `ar` | العربية | `hi` | हिन्दी |
| `pa` | ਪੰਜਾਬੀ | `ur` | اردو |
| `bn` | বাংলা | `sd` | سنڌي |

### How localization works

- **Source strings** live in `lib/l10n/app_en.arb` (the English template). Each non-English locale has a sibling `app_<code>.arb` file. Add a key in `app_en.arb` and provide a translation in every other `.arb` file.
- **Generated Dart code** lives in `lib/core/l10n/app_localizations*.dart` and is regenerated by `flutter pub get` / `flutter gen-l10n`. The build reads `l10n.yaml` for the configuration.
- **At runtime**, every screen that displays a user-visible string reads it via `AppLocalizations.of(context).someKey` — for example `AppLocalizations.of(context).tabToday`. There is one source of truth: the `.arb` files. The selected language is held in `localeProvider` (a Riverpod `Notifier<Locale?>`) and passed to `MaterialApp.router` as `locale:`.

### Adding or changing a string

1. Open `lib/l10n/app_en.arb` and add the new key, e.g. `"myNewLabel": "My new label"`.
2. Add the same key (with the translated value) to every other `lib/l10n/app_<code>.arb` file.
3. Use it in a widget:
   ```dart
   final l10n = AppLocalizations.of(context);
   Text(l10n.myNewLabel);
   ```
4. Run `flutter pub get` so the gen-l10n tool regenerates the Dart files.

## Project layout

```
lib/
├── main.dart                 # Bootstrap, Supabase init, splash state machine
├── app.dart                  # MaterialApp.router with locale + theme
├── core/
│   ├── env.dart              # Environment variables
│   ├── l10n/                 # Generated AppLocalizations (regenerated by pub get)
│   ├── widgets/
│   │   └── locale_provider.dart  # Riverpod Notifier<Locale?> + supportedAppLocales
│   └── theme/                # Colors, theme
├── router/app_router.dart    # go_router routes
├── l10n/                     # Source ARB files (the source of truth for translations)
└── features/
    ├── auth/                 # Sign in / sign up
    ├── my_day/               # Personal tab
    ├── history/              # Last 7 days timeline
    ├── left_behind/          # Missed task recovery
    ├── medals/               # Trophy room
    ├── progress/             # Progress tab
    ├── settings/
    │   ├── settings_screen.dart       # Settings + language picker
    │   └── help_support_screen.dart   # Help & Support + contact form
    └── shell/                # Bottom navigation
```

## Build release AAB (Play Store)

```powershell
flutter clean
flutter pub get
flutter build appbundle --release --dart-define-from-file=env.json
```

Output: `build/app/outputs/bundle/release/app-release.aab`

Upload this `.aab` file to **Google Play Console → Release → Production**.
