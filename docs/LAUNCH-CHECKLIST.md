# LeanSpace — Launch Checklist

A pre-flight check before submitting `com.leanspace.leanspace` to the
Google Play Store. Walk through every item and tick the box.

## 1. Build environment

- [ ] `flutter --version` reports the same SDK the team committed to
- [ ] D1 migrations have been applied to the production database:
      ```bash
      cd cloudflare-workers
      npx wrangler d1 migrations apply daily-stitch-db --remote --env production
      ```
- [ ] Worker deployed to production:
      ```bash
      cd cloudflare-workers
      npx wrangler deploy --env production
      ```
- [ ] Worker secrets configured:
      - `GOOGLE_SERVICE_ACCOUNT_JSON` — Google Play service account credentials
      - `PLAY_PUBSUB_TOKEN` — shared token for Google Pub/Sub push subscription
- [ ] `env.json` exists in `leanspace/` with production values:
      ```json
      {
        "API_BASE_URL": "https://daily-stitch-api.<your-subdomain>.workers.dev",
        "GOOGLE_CLIENT_ID": "<your-google-web-client-id>.apps.googleusercontent.com"
      }
      ```
- [ ] **Security: Verify `feature_flags.dart` has `unlockAllFeatures = false` and `enableSubscriptions = true`**

## 2. Google Play Console

- [ ] App created with package name `com.leanspace.leanspace`
- [ ] Default language English (United States)
- [ ] Store listing:
  - [ ] App name: "Daily Stitch"
  - [ ] Short description: 80 chars
  - [ ] Full description: 4000 chars
  - [ ] 8 screenshots (1080×1920 minimum) covering: Today, Progress,
        Medals, History, Add task, Settings
  - [ ] Feature graphic: 1024×500
  - [ ] App icon: 512×512 (already generated by `flutter_launcher_icons`)
- [ ] Content rating: complete the IARC questionnaire. Expect "Everyone".
- [ ] Target API level: latest stable (Flutter sets this automatically).
- [ ] Privacy policy URL hosted on a public domain (the Play Console
      rejects `localhost`).
- [ ] Data Safety form completed:
  - [ ] Data collected: email, task text, completion timestamps
  - [ ] Data shared: none
  - [ ] Data encrypted in transit: yes (HTTPS)
  - [ ] User can request deletion: yes (Settings → Account deletion)
- [ ] Ads: no. Leave the "Contains ads" toggle off.
- [ ] In-app purchases:
  - [ ] Monthly subscription created with id
        `leanspace_pro_monthly` (set price tier matching the
        paywall string)
  - [ ] Yearly subscription created with id
        `leanspace_pro_yearly` (set price tier; the paywall shows the
        real price string)
  - [ ] Both products are "Active" and "Available for purchase" in the
        Billing dashboard
- [ ] App signing: Play App Signing is enabled. Upload key generated
      with `keytool -genkey -v -keystore ~/keystores/lean-space.jks
      -keyalg RSA -keysize 2048 -validity 10000 -alias leanspace`.
      The keystore is stored in a team password manager.

## 3. Build & smoke test

- [ ] `dart analyze lib` reports 0 issues (run in repo root)
- [ ] `flutter test` passes
- [ ] `flutter build apk --release --dart-define-from-file=env.json`
      succeeds
- [ ] The release APK installs on a clean device
- [ ] Manual smoke test on a clean device:
  - [ ] Onboarding completes and lands on the auth screen
  - [ ] Email sign-up creates a real user
  - [ ] Adding a task, completing it, and re-opening shows a streak = 1
  - [ ] The home-screen widget installs and reflects the streak
  - [ ] Tapping "Last 7 days" opens the history screen
  - [ ] Tapping the locked 4th habit slot opens the paywall
  - [ ] Tapping the Pro upgrade card on the You tab opens the paywall
  - [ ] Completing a sandbox Pro purchase flips the user to Pro
  - [ ] Restoring a purchase on a fresh install flips the user to Pro
  - [ ] Uninstalling does not cancel a live subscription (verified in
        Play Console → Subscriptions)
  - [ ] Sign-out returns to the auth screen
  - [ ] Account deletion removes the user and all associated data
- [ ] No `buddy` / `Budd` / `accountability` strings appear anywhere
      in the app
- [ ] No "Growth Guardian" branding appears in the UI (only the
      in-code comments; safe to keep)

## 4. Privacy & legal

- [ ] Privacy policy live at a public URL; linked from the auth
      screen and the Play Store listing
- [ ] Terms of service live at a public URL; linked from the paywall
- [ ] Support email `dailystitch79315@gmail.com` is monitored
- [ ] The settings page exposes a way to: export all data, request
      account deletion, and view subscription status

## 5. Submit

- [ ] Internal testing track has 5+ testers for 7 days
- [ ] Crash rate < 0.5% in internal testing
- [ ] `flutter build appbundle --release --dart-define-from-file=env.json`
      produces the AAB to upload
- [ ] Upload to the internal track
- [ ] After 24h with no regressions, promote to closed beta
- [ ] After 7 days with no regressions, promote to production
- [ ] Set rollout to 5% for the first 24h, then 20%, then 100%
- [ ] Watch:
  - [ ] Play Console crash reports
  - [ ] Play Console ANR reports
  - [ ] Play Console subscription retention
  - [ ] Cloudflare Workers logs for failed purchases
  - [ ] `app_opens` retention cohorts (D1, D7, D30)
